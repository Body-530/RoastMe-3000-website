# 🔥 RoastMe 3000

A fun web app that delivers random, family-friendly roasts at the click of a button. Whether you're a developer, gamer, student, or just looking for a laugh, RoastMe 3000 has something ridiculous to say.

## ✨ Features

* 🎲 Random harmless roasts
* 🎭 Multiple roast categories

  * Beginner
  * Savage
  * Developer
  * Gamer
  * School
  * AI
* 🌙 Dark mode
* 📋 Copy roast to clipboard
* 📊 Roast statistics
* ✨ Smooth animations
* 🏆 Rare "Legendary" roasts with special effects
* 🥚 Hidden Easter eggs

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Press the **Roast Me** button and enjoy the chaos!
