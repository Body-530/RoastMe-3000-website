# RoastMe-3000-website
# 🔥 RoastMe 3000 😈

> **RoastMe 3000** is a fun, interactive web application that generates random, family-friendly roasts with animations, sound effects, achievements, XP, dark mode, and plenty of chaotic surprises.

The goal of this project is to practice front-end web development using **HTML**, **CSS**, and **Vanilla JavaScript** while creating an entertaining user experience.

---

# 📸 Features

* 🔥 Random roast generator
* 🎭 Multiple roast categories
* 🤖 AI-style roasting assistant
* 🎨 Animated user interface
* 🌙 Dark / Light mode
* 📋 Copy roast to clipboard
* 🏆 Achievement system
* ⭐ XP & Level progression
* 🪙 Coin counter
* 💀 Legendary roasts
* 🎲 Chaos Mode
* 📱 Responsive design
* 🥚 Hidden Easter eggs
* ✨ Smooth animations

---

# 🛠 Built With

* HTML5
* CSS3
* Vanilla JavaScript

No frameworks or external libraries are required.

# ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/Body-530/RoastMe-3000-website.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

No installation or server is required.
